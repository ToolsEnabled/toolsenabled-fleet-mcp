# ToolsEnabled Fleet MCP

Vendor distribution boundaries and current review status: [docs/PLUGIN-POLICY.md](docs/PLUGIN-POLICY.md).

This repository contains the standalone Fleet MCP source and its coordination-only
Codex package. The source now includes published Fleet 1.9.1 from
[toolsenabled-engine](https://github.com/ToolsEnabled/toolsenabled-engine/tree/fleet-mcp-1.9.1-source),
plus the [maintenance candidate](docs/MAINTENANCE-20261019.md).
The Claude Code plugin is a separate product with separate versions.

Use [CODEX.md](CODEX.md) for the Codex package, the [host guide](docs/HOST-MODE.md)
for Linux/WSL, or the [OpenShell installer guide](installer/openshell/README.md).
The existing published 1.9.1 archives are on [toolsenabled.ai](https://toolsenabled.ai).
This candidate is not a newly qualified runtime archive or a directory approval.
